# РИТМ — офлайн CRM для студии красоты

Настольное приложение для небольшой студии красоты: расписание, записи клиентов, прайс услуг, клиентская база и статистика. Работает полностью без интернета — данные хранятся в локальной базе на компьютере.

Интерфейс и данные — на русском языке, цены — в рублях. Приложение рассчитано на экран 1440×1000 (минимальный размер окна — 1200×800).

## Возможности

- **Расписание** на день, месяц и год с фильтром по специалисту, переходами по датам и сводкой по загрузке и плановой выручке.
- **Записи**: клиент, специалист, дата, время, статус, несколько услуг, комментарий; проверка пересечений по времени и запрет сохранения конфликтующей записи.
- **Услуги**: категории, поиск, сортировка, цены, длительность, себестоимость для расчёта прибыли, архивирование и защита от удаления использованных услуг. Услугу можно создать прямо из карточки записи в расписании.
- **Клиенты**: контакты, комментарий и заметки, история визитов, количество визитов и сумма покупок.
- **Статистика**: выручка, число записей, проданные услуги, средний чек и прибыль; недельный график, выручка по специалистам, лидеры продаж и экспорт CSV.
- **Настройки**: информация о студии и рабочие часы, специалисты, категории услуг, резервное копирование JSON и полная очистка.
- **Первый запуск**: пошаговый мастер настройки студии, команды и прайса. Демо-данные не загружаются.

## Быстрый старт

Требуется Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173/`.

### Настольная версия

```bash
npm run desktop
```

Команда собирает фронтенд и открывает его в Electron. Для сборки переносимого `.exe`:

```bash
npm run dist:win
```

Готовый файл появится в `release/RITM-CRM-0.1.0-portable.exe`. Установка не требуется: файл можно запускать с рабочего стола или внешнего диска.

## Хранение данных

- Все данные лежат в IndexedDB внутри профиля приложения.
- В настольной версии база размещается в `%APPDATA%\RITM-CRM` и не зависит от папки, из которой запущен `.exe`.
- Приложение не отправляет данные в сеть: шрифты, стили и скрипты упакованы локально.
- **Резервная копия** — «Настройки → Данные → Скачать копию». JSON-файл содержит услуги, клиентов, записи и настройки. Импорт полностью заменяет текущую базу.
- Очистка кэша браузера (в веб-версии) или папки профиля приложения удалит данные. Без резервной копии восстановить их невозможно.

## Первый запуск

При первом запуске приложение открывает мастер настройки и не заполняет базу демонстрационными данными. Мастер состоит из четырёх шагов:

1. **Студия** — название, адрес, телефон и рабочие часы.
2. **Команда** — специалисты, их роли и цвета в расписании.
3. **Прайс** — категории, услуги, цены и длительность. Шаг можно пропустить и добавить услуги позже.
4. **Готово** — проверка введённых данных и переход к расписанию.

После завершения мастера все данные можно изменить в разделе «Настройки». Если прайс пуст, услугу можно добавить в разделе «Услуги» или прямо из карточки записи в расписании.

- «Настройки → Данные → Очистить всё» — удалить все данные и снова открыть мастер настройки.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер Vite |
| `npm run build` | Проверка типов и production-сборка в `dist/` |
| `npm run preview` | Просмотр production-сборки |
| `npm run typecheck` | Проверка TypeScript без сборки |
| `npm run test` | Unit-тесты (Vitest) |
| `npm run desktop` | Сборка и запуск в Electron |
| `npm run dist:win` | Переносимый `.exe` для Windows |

## Структура проекта

```
electron/            Electron main-процесс и протокол app://
src/app/             Каркас: сайдбар, топбар, layout
src/components/ui/   Базовые компоненты интерфейса
src/domain/          Типы, даты, деньги
src/db/              Dexie-схема и репозитории
src/features/        Формы и представления расписания, услуг, клиентов, мастер первого запуска
src/pages/           Экраны приложения
docs/mockups/        Исходные макеты
docs/screens/        Скриншоты реализованных экранов
```

## Технологии

React 18, TypeScript, Vite, Tailwind CSS, Dexie (IndexedDB), React Router, Recharts, Radix UI, Lucide, Manrope, Electron и electron-builder.

## Ограничения

- Однопользовательский режим: у приложения нет сервера и синхронизации между устройствами.
- Для переноса на другой компьютер используйте экспорт/импорт JSON.
- Данные не шифруются на диске — доступ к ним определяется учётной записью Windows.
